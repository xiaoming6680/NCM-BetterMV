# BetterMV

**为网易云音乐中的每一首歌，实时生成专属 MV。**

播放歌曲后，点击播放栏上方的 MV（或按 Ctrl+Shift+M）。BetterMV 先分析整首歌曲，<br>
再以封面构建 3D 场景、按节拍剪辑镜头，全部在本机实时生成。

**开发中**：当前为预发布的开发版，仍有一些已知问题，欢迎试用和反馈。

[开发版下载](https://github.com/xiaoming6680/NCM-BetterMV/releases) · [更新记录](CHANGELOG.md) · [问题反馈](https://github.com/xiaoming6680/NCM-BetterMV/issues)

</div>

## 功能

- **歌曲分析**：识别速度、节拍，以及前奏、主歌、副歌、drop 等段落。镜头按段落切换，动作落在重拍上；drop 处进入推进隧道。
- **以封面构建场景**：场景的色彩、明暗与构图取自封面。每首歌的画面各不相同，黑白封面生成黑白 MV。
- **风格随歌曲变化**：快歌、电子为“律动”，慢歌为“抒情”，说唱为“字”，国风为“墨”。根据网易云的曲风标签和音频自动选择，也可手动指定。
- **歌词同步**：歌词逐词出现；有逐字歌词时按逐字时间显示，有翻译时附带翻译。仅有逐句歌词的歌曲，可安装对齐包，按音频对齐每个字。
- **专属晶体**：每首歌生成一颗晶体，形状由速度、鼓点和人声决定，在开场、drop 前和结尾出现。

## 设置

<p align="center"><img src="docs/images/settings.jpg" alt="设置页" width="620"></p>

- **风格**：自动，或固定为律动、抒情、字、墨。
- **画质**：画面卡顿时调为中或低。
- **画面延迟**：使用蓝牙耳机时画面会早于声音，可调为 +150～250 ms；也可在 MV 页右上角的设置中实时调整。
- **MV 按钮、控制栏**：可关闭播放栏上方的按钮，改用 Ctrl+Shift+M 打开。
- **场景**：可单独关闭不需要的场景，鼠标悬停时显示示意图。
- **逐字对齐（可选）**：仅有逐句歌词的歌曲，逐字时间按音节估算。下载对齐包（约 400 MB）后，按音频识别每个字的演唱时间；首次播放时在本机后台分析（数秒至半分钟），结果缓存后复用。

MV 页快捷键：空格播放 / 暂停，← → 快退 / 快进，↑ ↓ 调节音量，Esc 退出。

## 安装开发版

BetterMV 是 BetterNCM 插件，目前尚在开发，暂未上架 BetterNCM 插件商店。如需试用，请下载预发布的开发版：

1. **安装 BetterNCM**：下载并运行 [BetterNCM 安装器](https://github.com/std-microblock/BetterNCM-Installer/releases)，点击“安装”。BetterNCM 是网易云音乐 PC 版的开源插件管理器，已安装可跳过此步。
2. **添加 BetterMV**：从 [Releases](https://github.com/xiaoming6680/NCM-BetterMV/releases) 下载标记为 Pre-release 的开发版 `.plugin` 文件，放入 BetterNCM 的插件文件夹（默认 `C:\betterncm\plugins`）。
3. **重启网易云音乐**：播放歌曲，点击播放栏上方的 **MV**，或按 **Ctrl+Shift+M**。

运行环境：Windows、网易云音乐 3.x、BetterNCM 1.3.4 或更高版本，显卡需支持 WebGL 2。目前仅在网易云音乐 3.1.37 + BetterNCM 1.3.4 上测试过。

## 已知问题

- **首次打开需等待数秒**：需要先读取并分析整首歌曲。分析在主线程分片进行（网易云的内核不允许插件使用后台线程）。再次打开同一首歌无需等待。
- **段落划分不一定准确**：在 12 首标注过的歌曲上，段落名称按时长计算的准确率为 99%；未标注的歌曲可能把铺垫识别为副歌，或边界偏差一两小节，导致镜头在不恰当的位置切换。
- **风格依赖网易云的曲风标签**：无标签的歌曲只能依据鼓点和是否有 drop 判断，说唱、国风等在无标签时无法识别，可在设置中手动指定。
- **逐字时间为估算**：无逐字歌词的歌曲，每个词的时间按音节估算，与实际演唱存在偏差；安装对齐包后按音频对齐，但括号内的和声、重度处理的人声和日语歌词中的汉字仍可能不准。
- **人声切片的“卡顿重复”较少出现**：目前仅由歌词触发，而网易云的歌词很少标出切片。
- **测试范围有限**：仅在一台 RTX 5070 Ti 笔记本上测试过，集成显卡和其他网易云版本尚未测试；如出现卡顿，请将画质调为中或低。

## 后续计划

- 为分析结果给出可信度，在不确定处减少卡点运镜和切换。
- 从音频中识别人声切片，不再只依赖歌词。
- 更多场景，例如雕版排线、无限嵌套的画中画。
- 在更多电脑和网易云版本上测试。

**欢迎反馈**：段落划分有误、风格不合适、画面卡顿或场景观感不佳，都欢迎在 [Issues](https://github.com/xiaoming6680/NCM-BetterMV/issues) 中反馈，附上歌曲名称会很有帮助。

## 常见问题

**打开后为什么要等待几秒？**
首次打开一首歌时，BetterMV 需要读取并分析整首歌曲，通常需要几秒；再次打开同一首歌无需等待。

**是否需要联网？会上传哪些内容？**
音频使用网易云的本地缓存，未缓存完整时按标准音质向网易云获取；歌词、封面和曲风标签同样从网易云获取。对齐包从 GitHub 下载一次，之后在本机运行。所有画面在本机生成，不上传任何数据。

**画面卡顿、风扇噪音大？**
在设置中将画质调为中或低。MV 使用显卡实时渲染，集成显卡建议选“低”。

**画面与声音不同步？**
在设置中调整“画面延迟”：画面早于声音时向 + 调。

**风格选择不合适？**
可在设置中手动指定风格，也欢迎反馈具体歌曲。

**安装 BetterNCM 后网易云无法打开？**
重新运行 BetterNCM 安装器并点击“卸载”，即可恢复。

## 开发者

需要 [Bun](https://bun.sh)。开发说明、风格手册和验证记录见 [docs/](docs/)。

```sh
bun install
bun run dev      # 浏览器预览：http://localhost:5190/?id=歌曲ID（歌曲需已在网易云中完整播放一遍）
bun run plugin   # 安装到 BetterNCM 的开发插件目录，重启网易云后生效
bun run pack     # 打包为 dist/ncm-better-mv.plugin
```

插件预览图和 README 配图的源文件位于 `film/`（`bun film/render.ts --images`）。可选对齐包的源码、构建和评测见 `tools/aligner/` 与 [docs/ALIGNER.md](docs/ALIGNER.md)。
