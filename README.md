# BetterMV

**为网易云音乐中的每一首歌，实时生成专属 MV。**

播放歌曲后，点击播放栏上方的 MV（或按 Ctrl+Shift+M）。BetterMV 先分析整首歌曲，<br>
再以封面构建 3D 场景、按节拍剪辑镜头，全部在本机实时生成。

[下载](https://github.com/xiaoming6680/NCM-BetterMV/releases/latest) | [更新记录](CHANGELOG.md) | [问题反馈](https://github.com/xiaoming6680/NCM-BetterMV/issues)

</div>

## 功能

- **歌曲分析**：识别速度、节拍，以及前奏、主歌、副歌、drop 等段落。MV 以这首歌的分析开场：整首歌的响度绕成一圈光柱，段落一目了然；镜头按段落切换，动作落在重拍上。
- **以封面构建场景**：场景的色彩、明暗与构图取自封面。每首歌的画面各不相同，黑白封面生成黑白 MV。
- **风格随歌曲变化**：快歌、电子为“律动”，慢歌为“抒情”，说唱为“字”，国风为“墨”，每种风格有各自的场景。根据网易云的曲风标签和音频自动选择，也可手动指定。
- **歌词在场景之中**：一句歌词作为一个整体立在场景里，随演唱逐词出现，有翻译时附带翻译；每首歌选用一种字体。有逐字歌词时按逐字时间显示；仅有逐句歌词的歌曲，可安装对齐包，按音频对齐每个字。
- **每次播放都不同**：场景顺序、镜头与画风每次重新编排，也可在设置中固定。部分段落改用孔版印刷、像素、字符或录像带画风呈现。
- **专属浑天仪**：每首歌生成一架浑天仪，环数、刻度与咬合节奏由段落、拍号和鼓点决定，在开场、drop 前和结尾出现。

## MV 页

<p align="center"><img src="docs/images/controls.jpg" alt="MV 页：控制栏与播放列表" width="880"></p>

MV 页底部为播放控制（喜欢、切歌、播放模式、进度、音量、播放列表），进度条按段落分格，悬停时显示段落与时间；右上角为设置、最小化、最大化和退出。鼠标静止时控制栏自动隐藏。设置与播放列表从右侧滑出。

快捷键：空格播放 / 暂停，← → 快退 / 快进，↑ ↓ 调节音量，Esc 退出；网易云自身的快捷键（如 Ctrl+← → 切歌）同样有效。以上快捷键均可在设置中修改。

## 设置

<p align="center"><img src="docs/images/settings.jpg" alt="设置页" width="620"></p>

- **风格**：自动，或固定为律动、抒情、字、墨。
- **画面编排**：同一首歌每次播放时重新编排场景与镜头，或固定为同一种；在 MV 页的设置中可随时“换一种”。
- **画质、帧率上限**：画面卡顿时调为中或低；帧率上限可设为不限、240、120、60 或 30，高刷新率屏幕可选 120 或 240，设为 30 可明显降低显卡占用。
- **提前分析下一首**：播放时在后台分析播放列表中的下一首，切歌后无需等待。
- **画面延迟**：使用蓝牙耳机时画面会早于声音，可调为 +150～250 ms；也可在 MV 页右上角的设置中实时调整。
- **MV 按钮、控制栏**：可关闭播放栏上方的按钮，改用快捷键（默认 Ctrl+Shift+M）打开。
- **快捷键**：点击后按下新的组合键即可修改，与其他动作重复时两者互换，可恢复默认。
- **场景、画风**：每项附示意图，可单独关闭不需要的场景或画风，选择后点击“应用”生效；鼠标悬停时显示说明。
- **逐字对齐（可选）**：仅有逐句歌词的歌曲，逐字时间按音节估算。下载对齐包（约 400 MB）后，按音频识别每个字的演唱时间；首次播放时在本机后台分析（数秒至半分钟），结果缓存后复用。

## 安装

BetterMV 是 BetterNCM 插件，暂未上架 BetterNCM 插件商店，请从 GitHub 下载安装：

1. **安装 BetterNCM**：下载并运行 [BetterNCM 安装器](https://github.com/std-microblock/BetterNCM-Installer/releases)，点击“安装”。BetterNCM 是网易云音乐 PC 版的开源插件管理器，已安装可跳过此步。
2. **添加 BetterMV**：从 [Releases](https://github.com/xiaoming6680/NCM-BetterMV/releases/latest) 下载最新版本的 `.plugin` 文件，放入 BetterNCM 的插件文件夹（默认 `C:\betterncm\plugins`）。更新时先删除旧版本的 `.plugin` 文件。
3. **重启网易云音乐**：播放歌曲，点击播放栏上方的 **MV**，或按 **Ctrl+Shift+M**。

运行环境：Windows、网易云音乐 3.x、BetterNCM 1.3.4 或更高版本，显卡需支持 WebGL 2。目前仅在网易云音乐 3.1.37 + BetterNCM 1.3.4 上测试过。

## 已知问题

- **首次打开需等待数秒**：需要先读取并分析整首歌曲，一首四分半的歌约 3 秒。开启“提前分析下一首”后，顺序播放时切歌无需等待；再次打开同一首歌也无需等待。
- **段落划分不一定准确**：对照网易云为每首歌标出的副歌片段，188 首歌中 85% 的副歌被识别为副歌或 drop；其余可能把铺垫识别为副歌，或边界偏差一两小节，导致镜头在不恰当的位置切换。
- **风格依赖网易云的曲风标签**：无标签的歌曲只能依据鼓点和是否有 drop 判断，说唱、国风等在无标签时无法识别，可在设置中手动指定。
- **逐字时间为估算**：无逐字歌词的歌曲，每个词的时间按音节估算，与实际演唱存在偏差；安装对齐包后按音频对齐，但括号内的和声、重度处理的人声和日语歌词中的汉字仍可能不准。
- **少数场景的歌词仍可能被遮挡**：个别机位下歌词会被场景中的物体挡住或排到画面边缘。
- **测试范围有限**：仅在一台 RTX 5070 Ti 笔记本上测试过，集成显卡和其他网易云版本尚未测试；分形等场景对显卡要求较高，如出现卡顿，请将画质调为中或低，或在设置中关闭这些场景。

## 常见问题

**打开后为什么要等待几秒？**
首次打开一首歌时，BetterMV 需要读取并分析整首歌曲，通常需要几秒；再次打开同一首歌无需等待。开启“提前分析下一首”可省去切歌时的等待。

**是否需要联网？会上传哪些内容？**
音频使用网易云的本地缓存，未缓存完整时按标准音质向网易云获取；歌词、封面和曲风标签同样从网易云获取。对齐包从 GitHub 下载一次，之后在本机运行。所有画面在本机生成，不上传任何数据。

**画面卡顿、风扇噪音大？**
在设置中将画质调为中或低，或将帧率上限设为 30。MV 使用显卡实时渲染，集成显卡建议选“低”。

**画面与声音不同步？**
在设置中调整“画面延迟”：画面早于声音时向 + 调。

**同一首歌每次画面都不一样？**
这是默认设置。如需固定，在设置中将“画面编排”改为固定。

**风格选择不合适？**
可在设置中手动指定风格，也欢迎反馈具体歌曲。

**安装 BetterNCM 后网易云无法打开？**
重新运行 BetterNCM 安装器并点击“卸载”，即可恢复。

## 开发者

需要 [Bun](https://bun.sh)。开发说明、风格手册和验证记录见 [docs/](docs/)。

```sh
bun install
bun run dev      # 浏览器预览：http://localhost:5190/?id=歌曲ID（歌曲需已在网易云中完整播放一遍）
bun run plugin   # 安装到 BetterNCM 的开发插件目录，重启网易云后生效
bun run pack     # 打包为 dist/ncm-better-mv.plugin
```

插件预览图和 README 配图的源文件位于 `film/`（`bun film/render.ts --images`），宣传片见 [docs/FILM.md](docs/FILM.md)。可选对齐包的源码、构建和评测见 `tools/aligner/` 与 [docs/ALIGNER.md](docs/ALIGNER.md)。
