# BetterMV 发布流程

源码仓库：[xiaoming6680/NCM-BetterMV](https://github.com/xiaoming6680/NCM-BetterMV)。作者：XIAOMING6680。

## 构建与发布

1. 改动后同步递增 `plugin/manifest.json` 和 `package.json` 的版本，在 `CHANGELOG.md` 写这一版的变化（面向用户，不提任何作品名）。
2. `bun run pack` 生成 `dist/ncm-better-mv.plugin`：`manifest.json`、`bettermv.js`、预览图、`LICENSE`、字体及其许可证、场景与画风示意图。
3. 推送 `main`，等 “Build plugin” 工作流通过：类型检查、打包、检查安装包内容，并确认 `bettermv.js` 里没有“《”（插件单独宣传，界面上不出现作品名）。
4. 打 `v版本号` 标签，建 GitHub Release：附件是 `BetterMV-版本号.plugin`（即 `dist/ncm-better-mv.plugin` 改名）和 `SHA256SUMS.txt`。0.7.0 是预发布的开发版，0.7.5 起发正式版（用户 2026-10-05：“发正式版吧”）。插件的检查更新只认这个格式：标签 `v主.次.修`、非预发布、附件里有 `.plugin`，下载地址必须是本仓库的 `releases/download/`；改名或改格式前先改 `src/plugin/update.ts`。0.9.2 起新版本会自动删掉旧版本的包，说明里只需提醒从 0.9.1 及更早版本升级的人手动删掉旧的 `.plugin`（同 slug 的包只有文件名排在最后的生效，见 `docs/CLIENT.md`）。
5. 对齐包单独发在 `aligner-v1`（2026-10-05 发布），标成预发布，免得被 GitHub 标成最新版本；包的格式变了才发新标签，见 `docs/ALIGNER.md`。

本机装进 BetterNCM 的开发插件目录：`bun run plugin`，重启网易云。

## 客户端验收

在网易云 3.x + BetterNCM 1.3.4 里：

- 放一首歌，点 MV 和 Ctrl+Shift+M 都能打开；读取、分析、准备画面的提示依次出现，然后开始播放。
- 暂停、拖进度条、切歌时画面跟着走；Esc 退出后再打开同一首歌立刻播放。
- 设置页：风格、画质、画面延迟、MV 按钮、控制栏、场景开关都能生效，鼠标停在场景上显示示意图；MV 页右上角的齿轮打开同样的设置，在 MV 页里切换画质立刻变清晰或变糊。
- MV 页里：顶部能拖动窗口、双击最大化；四个角和右边缘能拉大缩小窗口（和网易云自己一样，左、上、下边缘不能拉）；右上角最小化、最大化 / 向下还原能用。
- MV 页控制栏：喜欢、播放模式和网易云自己的播放栏同步（在哪边改另一边都跟着变）；播放列表和网易云的一致，点一首切过去，正在播放的标红；Ctrl+← → 切歌（不是快进）；长歌名、长歌手名截断不压按钮，打开面板后右侧不压中间的按钮。
- 设置页标题旁和 MV 页设置面板标题旁的版本号与 `plugin/manifest.json` 一致。
- 更新：把上一版的包放进 `plugins`，启动后它会查到这一版、点“更新”下载、删掉自己的包，“重启网易云”后运行的是这一版；新旧两个包同时放进去，重启后旧的被删掉。测试方法见 `docs/CLIENT.md` 的“插件包的解压与更新”。
- 深色和浅色主题下设置页都看得清。

暂不上架 BetterNCM 插件商店（用户 2026-09-30），只在 GitHub 发布；0.7.5 起为正式版（用户 2026-10-05）。
