## 已经改了的

- **推进的冲击环一道接一道**（`drive.ts`）：原来只算最近一次底鼓的那一道环，下一个底鼓一来，前面还在往里跑的环当场消失（《Clarity》第一段 drop 里两个底鼓只隔 0.17 s，环才跑出去 14 个单位、还有七成亮就没了）。现在最近 1.3 s 内的底鼓各有一道环，按原来的速度和衰减一路跑进深处淡掉，环重叠时叠加但不超过一道满亮的环。原作《游戏是你的解药吗？》的 `tunnel.ts` 也是只算最后一道，只是那边画面元素多，不显。
- **图版第一次出现不再卡**：着色器原来在图版第一次切进来时才编译，每个图版第一次出现要 20–100 ms（掉 2–6 帧，网易云的 Chromium 91 更慢）。现在加载提示撤掉之前，把每个图版（连同暂时隐藏的物体）、动态图形层和转场着色器在离屏小画布上预画一遍（“准备画面…”），实测降到 3–11 ms。
- **三角隧道（铺垫）的冲击环**同样改成一道接一道。
- **丝滑转场**、**浮雕镜头**：已做，写进了 `TREATMENT.md` v0.7（转场一节、浮雕机位）。样片 `dev/samples/转场样片-溯.mp4`。
- **推进每 8 小节整条隧道跳一下**（审查发现）：已修。

## 转场要丝滑

现在的转场是“两个画面之间的平面擦除”（圆孔、横条、百叶窗…1/4–1/2 拍）、加速剪辑硬切、抒情段落之间压黑 0.6 s——画面是“换”过去的，不是“流”过去的。改成：

1. **运动接运动**：切点两边的镜头朝同一个方向、同样的速度在动（往前冲接往前冲，横移接横移）；段内的平面擦除大多换成**冲过去**——镜头朝上一幅的中心加速推进，进来的画面从那一点长出来、带着同样的速度继续推。
2. **形状匹配**（你《游戏》里键盘过孔接赛车圆环、《三角形》隧道出口的纸白三角铺满画面接纸面图版）：每个图版有一个出口形状和入口形状（隧道的框、律动环的圆、万花筒的中心、翻牌的方块），切点上前一幅的形状正好落成后一幅的形状，位置、大小对齐。
3. **封面做桥**（BetterMV 独有）：所有图版都是同一张封面搭的，转场时封面从上一幅的形态变成下一幅的形态——粒子聚成网点、碎片落成翻牌的方块、柱子压平成图版上的封面。
4. **同图版换机位**：不再甩镜切，两个机位之间连续运镜过去（半拍）。
5. 硬切只留给 drop 第一拍（最有冲击力）；抒情和墨不再压黑，改用慢的冲过去 / 封面变形。
6. 剩下的零星卡顿（新歌词、图版镜头开头现场画文字贴图，30–90 ms）：提前几拍在空闲帧里把下一镜要用的字画好。

## 要做进来的效果

**《游戏是你的解药吗？》**
- **隧道换世界**：推进（drop）每 4 小节换一种隧道——方框井 → 圆管膛线（螺旋槽）→ 六边形机库 → 公路（地面车道线、两侧路灯、前方尾灯拖尾）→ 封面像素方块矿道（墙是封面的像素块，底鼓时崩落）；换的时候 3 个单位内形状渐变（原片做法），不硬换。
- **子弹时间环绕**：drop 前的过门（现在是黑屏半拍）改成：慢动作环绕一颗发光的封面晶体，drop 第一拍它冲过镜头、白光炸开，进推进隧道。
- **霓虹灯管歌词**：没唱到的词是暗影，唱到时像灯管一样闪两下点亮（推进、隧道和律动的钩子句）。
- **叠层片头**：歌开头，歌名、歌手、专辑作为发光玻璃卡片一拍一张往镜头叠（后面的虚、暗，下面黑镜面倒影）——你那条开头弹窗叠层的做法；第一个重拍镜头冲进最前一张卡片，进第一个图版。

**《三角形》**
- **调试视图**（新图版“线框世界”）：封面当高度图生成一片低多边形地形，副歌 / drop 每拍换一种渲染视图（着色、线框、法线、深度等高线、重心、三角形编号、过度绘制、蓝图），新视图从上往下扫过旧视图，左上是调试面板和真实三角形数。
- **细分球**：封面贴在二十面体上，每半拍细分一次（20 → 80 → 320 → 1 280 → 5 120），新边亮起，之后随低音呼吸；给铺垫前半段。
- **错位拼合**（不可能三角的思路）：封面切成几块放在不同深度，普通角度看是散的；副歌第一拍镜头甩到唯一那个角度，碎块在画面上拼回完整封面。
- **坍缩收尾**：尾奏最后几小节，画面的三角形一片片脱落、螺旋吸进一点，剩一个三角形 / 光点，歌结束。

**pdoom（只借手法）**
- **钩子句逐次升级**：同一句钩子每出现一次换更重的排版：干净的墨底白字 → 信号色底墨字 → 细小字大片留白 → 频闪 + 层层轮廓；全屏一词一砸。
- **卡顿重复**：人声切片（“If our lo- lo-”这种）处，画面把最后半拍重复三遍。
- **指数分叉**：进 drop 前一小节，从画面中心长出线，每个八分音符分叉一次（1 → 2 → 4 → …），填满画面接 drop。
- **示波器**：纯音乐或前奏的安静段，示波器画出这首歌此刻的真实波形（荧光余辉），歌词骑在波形上。
- 另可做：雕版排线图版（给抒情 / 墨）、桥段的德罗斯特无限嵌套。

## 每首歌一个专属立体图形（用户新想法，待定方案）

用户：“对所有的歌曲提前出一独一无二的特征，在每首MV里都添加立体图形，这个立体图形的形状根据这个特征来，类似于Phigros的PV，可以上网查一下”

调研（B 站第八章《凌日潮汐》BV1EV4y1D7sQ、第九章《穹顶孤舟》BV16vbN6REhD 曲目预览，截帧看的）：
- Phigros 没有“每首歌一个专属形体”的设定，每首歌靠曲绘和角落的曲目卡区分；立体元素是整章共用的：方块、玻璃立方体阵列、白色水晶碎片炸开、金色环架里的发光球、八边形结构、立方碎块绕成螺旋。
- 画面：黑白单色打底 + 一个强调色（青 / 蓝，偶尔橙红）；玻璃和金属实体 + 强发光，线框只用在网格、经纬线、HUD 上；镜头俯冲、穿隧道、环绕主体；按鼓点硬切 + 故障 + 闪白；超大字加色差。
- 这类“一首歌对应一个形体”在设计上叫数据雕塑 / 声音雕塑，或生成式视觉识别（generative identity）。

形体的“身份”由全曲统计量一次定好（静态），跳动由实时的鼓点和电平驱动（动态）；参数只在事先挑好的好看档位里取，不连续映射，避免丑形状；颜色只取封面的。

| 方案 | 形体 | 特征怎么决定形状 |
|---|---|---|
| A 超级公式 | 两条超级公式（superformula）做球面乘积，像贝壳、花、星形的有机体 | 拍号 → 纬向对称；调性 → 经向对称 3/5/6/7/8；鼓密度 → 尖锐（越重越尖）；高频占比 → 圆润还是有棱；底鼓时突起一下，副歌多一阶对称 |
| B 谐波球 | 球面上叠球谐函数，一团饱满的“声音的形状” | 全曲音色（MFCC）→ 低阶起伏；12 维音高分布（chroma）→ 高阶细节；每类段落各算一套，换段落时形体变形 |
| C 晶体（推荐，最像 Phigros） | 多面体家族 + Conway 操作（切角、加尖、取对偶），玻璃面 + 发丝棱线 | 拍号 / 速度档位 / 曲风 → 基础多面体（四面、立方、八面、十二面、二十面…）；段落数、鼓密度 → 切角 / 加尖层数；速度波动 → 扭转；歌曲 ID 的哈希定剩下的细节，保证每首不同；棱线在节拍上闪，drop 时碎开再拼回 |

放在哪（建议，串起前面的几个效果）：片头叠层卡片上的徽记 → drop 前子弹时间环绕的就是它 → 推进隧道尽头的终点（现在是封面）→ HUD 角标 → 尾奏坍缩成它，歌结束。
