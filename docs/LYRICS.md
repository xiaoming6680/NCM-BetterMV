# 歌词

网易云歌词怎样变成 MV 里的句和词、什么时候上屏、哪些词换颜色。歌词接口见 [CLIENT.md](CLIENT.md)，逐字时间的对齐见 [ALIGNER.md](ALIGNER.md)。

测试：`bun run test:lyrics`（`tools/lyrics.test.ts`，Node 自带的测试运行器）。

## 解析（`src/lyrics/parse.ts`）

- 有逐字歌词（yrc）时用它的词时间；只有逐行歌词（lrc）时，一句的词按音节在句内摊开（`spreadWords`）。翻译（tlyric）按时间戳配到句子上。
- 作词作曲等署名、版权声明、段落标签、纯音乐提示不作为歌词。

### 分词（`tokenize`）

- 中文、日文假名、韩文一个字一个词；其他文字按空格切。
- 标点不单独成词：开括号、开引号并到后一个词，其余并到前一个词。
- 没有空格也拆开的两种情况（`splitJoined`）：逗号、分号、冒号、问号、感叹号（含全角）或省略号后面紧跟字母，如 `Thursday,October` 拆成 `Thursday,` 和 `October`；句点两侧各有至少两个字母，如 `end.Start`、`wait...what`。数字不拆（`1,000`、`10:30`、`3.14`），缩写不拆（`U.S.A.`、`a.m.`）。
- 逐字歌词里没有空格隔开的相邻片段合成一个词（网易云常把一个词拆成几个音节），但前一片段以上述标点结尾、后一片段以字母开头时不合并；一个片段里含两个词时按音节分它的时长。
- 缓存中的 622 首歌里，新拆分规则改动了 56 首共 239 处，几乎都是逗号后缺空格。

### 打字机式歌词（`src/lyrics/typed.ts`）

有的歌用逐行歌词模拟 MV 里逐字打出的文字：每隔零点几秒一行，每行是上一行多打一个词或一个字母、删掉一些、或改掉最后一个词（如括号里的计数）。《Credits EX》（405372425）279 秒有 759 行，434 个间隔不到 0.15 秒。原样作为 759 句时，任何场景都来不及把一句排出来下一句就到了。

- 判定（`mergeTyped`）：只用于逐行歌词。相邻两行间隔不超过 0.36 秒，且一行以另一行开头（多打或删掉），或两行开头至少两个字符、且不少于较短一行一半的字符相同（改掉最后一个词）。完全相同的两行只在间隔小于 0.15 秒时算作同一行：正常歌曲里重复喊同一个词每次间隔约 0.19–0.6 秒（《LEVEL UP!》），同一句连唱两遍间隔 0.3 秒（《Remember Me》），每唱一次都应重新上屏。
- 合并：一串这样的行合成一句，文字取其中词数最多的一行（相同时取较晚的一行），每个词从第一次以完整或部分打出的形式出现时开始，翻译取同一行的。合成的句子标记为 `typed`。
- 对齐包不处理 `typed` 句（任务里这些句子不带词）：词的时刻就是歌词自己打出的时刻。其他句子照常对齐。
- 缓存中的 622 首歌里只有《Credits EX》被合并：754 句（去掉署名后）合成 144 句，其中 79 句是合并出来的。

## 上屏时序（`src/director/lyrics.ts` 的 `LyricTrack`）

- 一句提前 0.5 秒入场。下一句在 2.5 秒内开唱时，这一句在它开唱前约 0.32 秒开始离场，否则唱完 0.8 秒后离场；离场用 0.3 秒。同时最多显示两句（离场的和入场的）。
- 与前后句挨得近时按间隔缩短：入场提前量不超过与上一句间隔的一半（`leadOf`），离场时长不超过到下一句间隔的四分之一（`exitOf`）。`typed` 句的离场时长还不超过“最后一个词到下一句”间隔的一半，最后一个词出现时句子还在原位。
- 固定的 0.5 秒和 0.3 秒用在行距 0.08 秒的歌上时，一句在开唱前就已离场，屏幕上始终是两句还没唱到、正在入场的歌词，正在唱的那句从不显示。
- 只影响间隔不到 1.2 秒的句子。缓存中《Credits EX》以外的 621 首歌共 14 648 句，离场缩短的 949 句，入场推迟的 590 句。

## 颜色词（`src/lyrics/colors.ts`）

写到颜色的词用那种颜色显示，如“蓝色”两个字显示为蓝色。解析时找出（`colorWords`），写入 `LyricWord.color`（sRGB 十六进制）。

- 中文、日文、韩文按一句的字连起来匹配，其他文字整词匹配（含复数和 -ish）。
- 总是表示颜色的字：红、蓝、绿、紫、黄、橙（含繁体、日文写法）。前面的修饰字（深、浅、火、血、天等）和后面的“色”一起上色。
- 只在部分词里表示颜色的字（白、青、金、银、粉、灰等）只认词表里的词：“白云”的“白”上色，“明白”不上色；“青山”上色，“青春”不上色。词表里方括号标出上色的部分。
- 不收黑色：深色画面上的字是浅色的，黑字会融进自己的深色光晕。
- 颜色是固定的一组，亮度与普通歌词相近，在深色画面上读得清。
- 上色的载体：`paintWord`（LyricRig、LyricLayer、LyricOrbit、LyricGates、LyricRing 共用）和 LyricBlocks（字的颜色和书写光笔的颜色）用这个颜色代替纸色，唱到时变亮，不再偏向 signal 色；叠字中含颜色词的整组字用这个颜色；图版里颜色词唱到时下面的色条用这个颜色（字仍是两色印刷）；浮雕的字用这个颜色。
- 不上色：浅色画面（字是烘进纹理的深色字，染色只会染到光晕）、点阵（只有三种 LED 颜色）、翻译。
- 缓存中的 622 首歌里有 53 首含颜色词，共 105 个词。
